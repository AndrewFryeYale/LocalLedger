How it works

Code does the counting. Agents do the reading. Nothing reaches a reader without a verbatim source.

Deterministic code ingests the records, scores the signals and builds every company's model. Language-model agents are used only where reading is needed: writing what changed, updating a model when a rule can't, and debating a print in the war room. Every agent's output passes through checks that don't trust the model.

Untrusted input

Documents are data, never instructions.

An input filter strips instruction-like text, hidden characters and forged document headers before any prompt; every prompt says document text must not be obeyed.

Invented facts

No verbatim source, no claim.

Quotes must match the stored document; numbers must appear in it; quotes from text flagged as injection are refused; an LLM verifier rereads the rest.

Runaway cost

Hard budget, loop guard, cache.

Each call reserves its cost against LLM_BUDGET_USD and falls back to a deterministic mock at the cap; war rooms are capped per hour; reruns of unchanged inputs are free.
