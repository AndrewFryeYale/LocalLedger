Defenses in code

  • Input filter (safety.py): every document passed to any prompt is scanned centrally in the LLM client; instruction-like spans, role tags, forged document headers and direction-override characters are removed and logged.
  • Prompt rule: every prompt that shows document text says it is untrusted data and must not be obeyed.
  • Output gates (research/factcheck.py): verbatim quote, numbers present in the source, quote not tainted by injection, no advice language, then an LLM verifier. A note with an uncited claim fails outright.
  • Bounded model updates: the LLM can propose at most 3 adjustments, each with a verbatim quote, factors 0.7-1.3x, added revenue at most 2x TTM.
  • Loop guard: a war room runs at most WARROOM_MAX_RUNS_PER_HOUR times; queued redirects merge into one rerun; each call retries at most once.
  • Budget: each call reserves its estimated cost against LLM_BUDGET_USD before it is sent and falls back to a deterministic mock at the cap.
  • Compliance: disclosure footer everywhere, publish block on held tickers, human approval before a war-room note is published.
