Efficiencies, with the evidence

  1. Reasoning effort per agent. Same prompts, same model: {{ '{:,.0f}'.format(b.tokens_reasoning) }} → {{ '{:,.0f}'.format(tu.tokens_reasoning) }} reasoning tokens per workload. "none" everywhere was cheaper still but dropped 2 of 8 notes at fact-check, so writing and checking agents keep "low".
  2. Retry with less reasoning, not the same request. In the baseline the war-room Note writer spent its entire 5,000-token budget on reasoning twice, returned nothing and fell back to the mock. A truncated call now retries one effort level lower.
  3. Code before models. {{ '%.1f%%'|format(t.ledger.model_impacts_without_llm_share * 100) }} of {{ '{:,}'.format(t.ledger.model_impacts) }} replayed signals updated the company models through deterministic rules; the LLM updater ran {{ t.ledger.model_impacts_by_llm }} times. Signal scoring, valuation and the whole backtest use no LLM.
  4. One note per source document. A bank's call-report extract yields up to four signals; they now share one note (253 → 234 notes for the current feed, -8%).
  5. Compute once, serve everyone. Research is written once a week and read by every subscriber, so the analyst tier has no per-user model calls. Only fund war rooms scale with users.
  6. Exact-match disk cache. Reruns of unchanged inputs cost $0 ({{ '%.0f%%'|format(t.ledger.disk_cache_hit_rate * 100) }} of all calls so far were cache hits). Provider prompt caching was tested and only hit on near-identical prompts, which the disk cache already makes free, so prompts weren't restructured for it.
